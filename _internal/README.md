# SmallSignal · 小信号方程化简

运行在 Windows 上的中文桌面软件，用于从模拟集成电路的小信号节点方程中消去中间电压、电流，得到目标表达式。所有计算和公式预览均在本机完成，运行时无需网络。

## 直接使用

双击 `release\SmallSignal\SmallSignal.exe`，或项目根目录下的 `start.bat`。

便携版已包含 Python、SymPy、KaTeX 和字体，无需安装 Python。移动或发送软件时，请保留整个 `SmallSignal` 文件夹，包含 `_internal`；也可以发送提供的 ZIP 并先解压。桌面窗口依赖 Microsoft Edge WebView2 运行环境，本机已可使用。若桌面窗口初始化失败，程序会自动改用默认浏览器，仍然只连接本机。

1. 左侧输入方程，每行一条，右侧立即显示公式；顶部省去大幅介绍区域。
2. 在输入区下方填写目标，例如 `V_{o}/V_{i}`。
3. 勾选所有待求未知量，包含输出量和中间变量；保留输入信号、电路参数和频率符号。
4. 点击“消元并化简”，或按 `Ctrl+Enter`。
5. 查看精确公式、成立条件、各未知量的解和矩阵方程。结果代回每一条原始方程后，残差必须全部严格等于 0，才会显示成功。

输出在最下方独占整行。可以切换因式形式、按频率排列、有理分式；长表达式自动分行并适配宽度。“展开结果”将结果区铺满窗口，按 Esc 或“返回工作台”恢复。关闭“整体适配”可以按原始字号查看。

“复制 KaTeX”复制当前排版对应的完整数学字符串，分组显示时包含全部系数定义；它经过内置 KaTeX 实际解析验证，不包含 `documentclass`、`usepackage` 等文档命令，也不附加美元符号。可以直接传给 `katex.render()`，或粘贴到 Markdown 的 `$$` 公式块内。“复制展开式”得到没有中间系数名的完整公式，同样使用 KaTeX 支持的语法。

“保存项目”保存为 JSON，包含方程、目标、未知量选择、频率符号。“打开项目”恢复文件。`Ctrl+S` 也能保存。“导出 KaTeX”输出与复制内容相同的 `.katex.txt` 文件。重要内容请显式保存到项目文件，浏览器草稿仅用于当前本机会话的刷新恢复。

## 已内置你的电路

默认示例即你给出的方程，另附“共源放大器”和“两级 RC 网络”。

你的方程中 `SC_2` 按你确认的含义改为 `S*C_{2}`，最后一行重复方程保留展示，求解时自动去重。默认设置：

- 目标：`V_{o}/V_{i}`。
- 待求未知量：`V_{1}`、`V_{x}`、`V_{y}`、`V_{o}`。
- 保留参数：`V_{i}`、`g_{m1}`、`g_{m2}`、`g_{m3}`、`g_{m5}`、`r_{o1}` 至 `r_{o4}`、`R_{2}`、`C_{C}`、`C_{2}`、`S`。

保存好的项目在 `examples/你的电路.json`，计算结果在 `examples/你的电路-计算结果.json`。

## 输入语法

KaTeX 是公式排版库。计算部分采用明确限定的 LaTeX 算术语法，不能计算的命令会提示错误，并定位到行/列。

| 用途 | 写法 |
| --- | --- |
| 标准下标 | `V_{o}`、`g_{m1}`、`r_{o2}` |
| 简写下标 | `V_o`、`g_m1`，完整字母数字作为一个下标，和标准写法等价 |
| 乘法 | `*`、`\cdot`、`\times`，或以空格分隔符号 |
| 除法 | `/`、`\frac{a}{b}`、`\dfrac{a}{b}`、`\tfrac{a}{b}` |
| 加减 | `+`、`-` |
| 幂 | `S^2`、`S^{2}`、`R^{-1}`、`**` |
| 括号 | `()`、`{}`、`[]`、`\left(…\right)` |
| 根号 | `\sqrt{2}` |
| 希腊字母 | `\omega`、`\beta` 等常见希腊字母 |
| 方程组 | 每行一条；也支持 `aligned`、`cases`、`align`、`gathered` 环境和 `\\` 换行 |
| 注释 | `%` 后为当前行注释 |

连续字母是**一个符号**，所以 `SC_{2}` 与 `S*C_{2}` 不同。`g_{m1}` 与 `g_{m}*1` 也不同。相乘推荐明确使用 `*`。符号大小写敏感，`S`、`s` 是不同参数；所有名字包括 `I`、`E`、`pi` 都视为电路符号，不会自动识别成虚数、自然常数或圆周率。

支持精确整数和小数，`0.1` 以 `1/10` 参与计算；幂指数须为绝对值不超过 12、分母不超过 12 的有理数。暂不支持科学计数法、微分、积分、三角函数、矩阵命令、分段表达式、单位和自定义宏。

## 数学范围与成立条件

第一版支持**对所选未知量呈线性**的方程组，系数可以是电路参数的有理式，也可以含频率变量和符号根号。例如 `g_{m}*V_{x}` 是线性的，只要仅将 `V_{x}` 勾选为待求未知量。`V_{x}*V_{y}` 在两者都勾选时是非线性的，会报错。原方程分母含待求未知量时也会拒绝，避免把非线性问题误算成线性问题。

内部将方程转成精确系数矩阵，按行清除参数分母，再进行分式无除法的行消元。求解后会：

- 消去中间变量、约去公共因子；不使用浮点近似。
- 将各未知量的解同时代回所有原方程，并精确化简残差为 0。
- 保留原式分母、目标分母和通用秩所需的非零条件，即使某些因子在结果中被约掉也不会遗失。
- 约束不足时，如果目标仍能唯一确定则给出结果并说明自由变量；否则报错。
- 检测一般参数条件下的矛盾、未知量间非线性、拼写错误和无定义目标。

结果是**列出的充分条件下的通用参数解**，不会枚举参数为零等所有特殊分支。若需研究某个奇异参数取值，应先在原方程中替换为该值后重新求解。传递函数 `V_{o}/V_{i}` 的普通比值定义要求 `V_{i}≠0`。软件不检查电路物理模型或 KCL 正负号，也不会自行采用 `g_m r_o≫1` 等近似。

最多 24 条方程、24 个待求未知量、80 个符号。计算超过 35 秒将结束该计算进程并提示，桌面界面仍可使用。上限是输入限制，并非保证每种复杂方程均能在时间内完成。

## 从源码运行和修改

在 Python 3.13 环境执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

仅使用本机浏览器：

```powershell
python app.py --browser
```

开发/测试服务（只监听本机回环地址）：

```powershell
python app.py --serve --port 8765
python -m unittest discover -s tests -v
node tests/test_math_layout.cjs
```

打包 Windows 便携版：

```powershell
python -m PyInstaller --noconfirm --distpath release SmallSignal.spec
```

主要文件：`engine.py` 为受限算式解析和消元引擎；`app.py` 为桌面窗口与本机服务；`static/` 为界面和离线公式资产；`tests/` 为计算验证。解析器不使用 `eval()` 或允许执行 Python 的字符串求值器。

界面验证覆盖左右公式预览、4 个未知量的默认选择、完整电路求解、按频率分组、长公式分行、结果展开/返回、错误定位、下标规范化、旧结果过期标记、项目保存与恢复、KaTeX 复制与导出；三种形式复制出的实际字符串都通过了内置 KaTeX 解析。
